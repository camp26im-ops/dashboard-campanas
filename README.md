# Dashboard de campañas · Imagen Médica

Página del dashboard de rendimiento de campañas de Google Ads de Imagen Médica,
publicada con GitHub Pages.

- **No se edita a mano.** Este repo se reemplaza completo cada mañana de forma
  automática desde un repositorio privado. Cualquier cambio hecho aquí se pierde.
- **Los datos van cifrados** (`datos.enc.json`, AES-256-GCM). Sin la contraseña
  el archivo es ilegible; la página la pide y descifra en el navegador.
- Para cambios en la página o en los datos, edita el repositorio privado.

| Archivo | Qué es |
| --- | --- |
| `index.html` | La página del dashboard |
| `datos.enc.json` | Datos cifrados que lee la página |
